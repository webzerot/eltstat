# Εφαρμογή Μηνιαίου Δελτίου Κίνησης Καταλύματος ΕΛΣΤΑΤ

Μια ολοκληρωμένη εφαρμογή επιφάνειας εργασίας γραμμένη σε Python και Tkinter, σχεδιασμένη για να αυτοματοποιεί την επεξεργασία των στατιστικών αρχείων Excel από το Protel PMS (αρχεία `Nationalities Statistics`) και να δημιουργεί αυτόματα τα επίσημα μηνιαία δελτία κίνησης τουριστικού καταλύματος της Ελληνικής Στατιστικής Αρχής (**ΕΛΣΤΑΤ**) σε μορφή PDF.

## Βασικές Λειτουργίες

* **Αυτοματοποιημένη επεξεργασία Excel:** Διαβάζει άμεσα τα φύλλα εξαγωγής του Protel, αθροίζει τις αφίξεις πελατών και τις διανυκτερεύσεις ανά χώρα και τις αντιστοιχίζει απευθείας στις κατηγορίες του δελτίου ΕΛΣΤΑΤ.
* **Έξυπνη αντιστοιχίσεις χωρών:** Αναγνωρίζει αυτόματα παραλλαγές ονομασιών χωρών (αγγλικές/ελληνικές ονομασίες, περιφερειακές ομάδες κ.λπ.) και επιτρέπει την αποθήκευση προσαρμοσμένων αντιστοιχίσεων που διατηρούνται διαχρονικά.
* **Ευέλικτες μέθοδοι συμπλήρωσης PDF:**
  * **Επικάλυψη σε template (Προεπιλογή):** Τοποθετεί τα δεδομένα στις ακριβείς θέσεις πάνω στο κενό έντυπο της ΕΛΣΤΑΤ.
  * **Έξυπνη διάταξη (Πειραματικό):** Εντοπίζει αυτόματα τυχόν μετατοπίσεις ή αλλαγές περιθωρίων σε νέες εκδόσεις του εντύπου.
  * **Επεξεργαστής χειροκίνητης διάταξης:** Ένας ενσωματωμένος οπτικός επεξεργαστής για μεταφορά πεδίων (drag-and-drop), ρύθμιση γραμματοσειρών, μεγεθών, χρωμάτων και διαχωρισμό κουτιών ψηφίων.
* **Πλήρες ιστορικό και στατιστικά:** Παρακολουθεί τις μηνιαίες υποβολές, προσφέρει διαδραστικά γραφήματα στηλών με συγκρίσεις προηγούμενου έτους, υπολογίζει βασικούς δείκτες (μέση διαμονή, ποσοστό αλλοδαπών) και εξάγει πλήρες ιστορικό σε Excel.
* **Ενσωματωμένος οδηγός χρήσης:** Διαθέτει διαδραστικό πάνελ βοήθειας με αναζήτηση, ελέγχους κατάστασης συστήματος σε πραγματικό χρόνο και συμβουλές.
* **Υποστήριξη Drag-and-Drop:** Σύρτε απευθείας αρχεία Excel, templates ή φακέλους PDF μέσα στην εφαρμογή (μέσω `tkinterdnd2`).
* **Δίγλωσσο περιβάλλον:** Υποστηρίζει πλήρως Ελληνικά και Αγγλικά με άμεση εναλλαγή από τις ρυθμίσεις (τα επίσημα έγγραφα PDF παραμένουν στα ελληνικά όπως ορίζει ο νόμος).

## Δομή Έργου

```text
├── main.py                       # Κύριο εκτελέσιμο αρχείο εφαρμογής
├── requirements.txt              # Απαιτούμενες βιβλιοθήκες Python
├── template_elstat_report.pdf    # Κενό πρότυπο PDF της ΕΛΣΤΑΤ
├── elstat_config.json            # Αρχείο ρύθμισης ενεργού φακέλου δεδομένων
└── ELSTAT_Data/                  # Προεπιλεγμένος φάκελος δεδομένων
    ├── hotel_settings.csv        # Αποθηκευμένα στοιχεία καταλύματος
    ├── elstat_history.csv        # Αρχείο ιστορικού κίνησης
    ├── elstat_months.csv         # Μηνιαίες ημέρες λειτουργίας και εργαζόμενοι
    ├── elstat_preferences.json   # Προτιμήσεις και ρυθμίσεις χρήστη
    ├── elstat_country_mappings.json # Προσαρμοσμένες αντιστοιχίσεις χωρών
    ├── elstat_manual_layout.json # Συντεταγμένες επεξεργαστή διάταξης
    └── ELSTAT_Archive/           # Αρχειοθετημένα αντίγραφα μηνιαίων PDF
```

## Εγκατάσταση και Εκτέλεση

### 1. Προϋποθέσεις
Βεβαιωθείτε ότι έχετε εγκατεστημένη την **Python 3.8 ή νεότερη**.

### 2. Εγκατάσταση Εξαρτήσεων
Ανοίξτε τοτερματικό (command prompt) στον φάκελο του έργου και εκτελέστε:
```bash
pip install -r requirements.txt
```

### 3. Εκτέλεση Εφαρμογής
```bash
python main.py
```

## Οδηγίες Χρήσης

1. **Καρτέλα «Στοιχεία ξενοδοχείου»:** Συμπληρώστε τα στοιχεία του καταλύματός σας και τον 9ψήφιο ΑΦΜ κατά την πρώτη εκτέλεση.
2. **Καρτέλα «Δελτίο μήνα» (Βήμα 1):** Μεταφέρετε με drag-and-drop το αρχείο Excel του Protel (`Nationalities Statistics`) ή κάντε κλικ στο **Επιλογή Excel…**.
3. **Βήμα 2:** Ελέγξτε την περίοδο και πληκτρολογήστε το **Σύνολο εργαζομένων** (συμπεριλαμβανομένων ιδιοκτητών/οικογένειας).
4. **Βήμα 3 & Δημιουργία:** Ελέγξτε τη διαδρομή αποθήκευσης και πατήστε **Δημιουργία PDF** (ή **Δημιουργία & Εκτύπωση**).
5. **Καρτέλα «Ιστορικό»:** Δείτε παλαιότερες υποβολές, ετήσια στατιστικά, εξαγωγή σε Excel ή επανατύπωση παλαιών μηνών.

## Συντομεύσεις Πληκτρολογίου

* `Ctrl + O`: Επιλογή αρχείου Excel Protel
* `Ctrl + Enter`: Δημιουργία αναφοράς PDF
* `Ctrl + P`: Δημιουργία & Εκτύπωση αναφοράς
* `Ctrl + F`: Αναζήτηση στον Οδηγό Χρήσης / Λίστα στοιχείων επεξεργαστή
* `F1`: Άνοιγμα ενσωματωμένου διαδραστικού οδηγού
* `Ctrl + S`: Αποθήκευση αλλαγών διάταξης (στον Επεξεργαστή)
* `Ctrl + Z` / `Ctrl + Y`: Αναίρεση / Επανάληψη (στον Επεξεργαστή)
* `Delete`: Διαγραφή επιλεγμένου μήνα ή προσαρμοσμένου στοιχείου
